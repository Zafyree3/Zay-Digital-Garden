Tags has an available tags [[Topics/Plugins\|Plugin]] by [[Topics/Obsidian\|Obsidian]] that organises notes by their following tags.

This effectively creates an automatic folder structure around tags instead of manually create your own.

Some people like this and does this instead.

Three main types:
1. main note type
2. status
3. in-line note type

used for "is a" note:
*is this a "blank" note
1. book?
	1. #source #book 
2. daily note
	1. #dailynote 
3. topic?
	1. #topic

can also be used to indicate status:
- #unread
- #read
- #notstarted
- #inprogress
- #completed

can also be used in line, example:
- #idea build an XXYYZZ app
- #task completed XXYYZZ by DD/MM/YY

tags can also be nest:
- #book/nonfiction
- #book/fiction
