# AED (Automated External Defibrillator)

## What it is
A portable device that analyses the casualty's cardiac rhythm **through the
electrode pads** and advises/delivers a shock if one is needed. Designed so a
lay rescuer can defibrillate — early defibrillation is the single biggest
survival lever in cardiac arrest.

## Use sequence (alongside [[Wiki/entities/cpr\|cpr]])
1. Turn on — follow the voice prompts
2. Bare the chest, attach pads (upper right chest, lower left side)
3. **Nobody touches the casualty during analysis or shock**
4. Deliver shock if advised → immediately resume CPR
5. Continue CPR between rhythm checks until EMS takes over

## Key facts
- Works with cardiac arrest only — it will not shock a non-shockable rhythm
- Use as soon as it arrives; don't delay CPR to fetch one if none is near
- Pads placement matters — see manual figures (BA 3.4/3.5)
