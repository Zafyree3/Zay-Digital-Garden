# Bleeding Control

## What it is
Stopping blood loss — the priority for severe wounds. Direct pressure is the
core move.

## Severe bleeding (verified from SFA manual)
1. **Apply direct pressure** to the wound (gloved hand)
2. Place a **clean dressing** over the wound
3. Apply a **bulky pad extending beyond the wound edges**, bandage firmly
4. If bleeding continues: **leave the first dressing in place**, bandage
   another on top (removing the first tears away clots)
5. **Tourniquet** for an amputated limb — **record the time** it was applied
6. If unresponsive + not breathing → start [[Wiki/entities/cpr\|cpr]] + [[Wiki/entities/aed\|aed]]

## Hygiene
- Gloves; wash with soap and running water after (blood/body-fluid exposure)
