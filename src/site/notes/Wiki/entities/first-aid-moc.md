# First Aid — Map of Content

> Core skills + the key numbers. Every entity links to its siblings — the
> insights live in those links (shared airway-first logic, shock prevention,
> the "call 995 first" reflex).

## ☎️ Key numbers (QRG, updated Nov 2024)
- SCDF Ambulance / Fire: **995** | Police: **999** (SMS: 71999)
- Non-emergency ambulance: **1777**

## Entities
- [[Wiki/entities/cpr\|cpr]] — 100–120/min, 4–6 cm depth, 30:2 (trained) / hands-only (lay)
- [[Wiki/entities/aed\|aed]] — rhythm analysis + shock; nobody touches during analysis
- [[Wiki/entities/recovery-position\|recovery-position]] — unconscious + breathing → side, unless spinal/head injury
- [[Wiki/entities/choking-fbao\|choking-fbao]] — partial: don't interfere; complete: back blows + abdominal thrusts
- [[Wiki/entities/bleeding-control\|bleeding-control]] — direct pressure, bulky pad, tourniquet + record time
- [[Wiki/entities/burns\|burns]] — running water; chemicals 15–20 min; cold compress ≤20 min

## The connective thread
Almost every skill here is **airway → breathing → circulation** in disguise:
[[Wiki/entities/choking-fbao\|choking-fbao]] protects the airway, [[Wiki/entities/recovery-position\|recovery-position]] keeps it clear,
[[Wiki/entities/cpr\|cpr]] replaces circulation when it stops, [[Wiki/entities/aed\|aed]] restarts the rhythm.
Spot the same ABC logic in other courses' notes — that's the cross-domain
insight this structure exists for.
