# Recovery Position

## What it is
Rolling an **unconscious but breathing** casualty onto their side so the
airway stays clear (tongue can't block it; fluids drain out).

## When to use
- Unresponsive AND breathing normally
- **Do NOT turn** if spinal or head injuries are suspected (SFA: "do not turn
  or [move] if spinal/head injuries are not suspected to be absent")
- Check for no severe injuries before placing

## Core idea
Airway first — the same principle as the airway check in [[Wiki/entities/cpr\|cpr]].
