# XTEINK X4 Pro

## What it is
A pocket-sized 4.3" e-ink e-reader from XTEINK (the X4 V2 refresh, ~USD 99).
72g, 5.95mm thin, built-in frontlight with adjustable colour, touchscreen,
1100 mAh battery, magnetic pogo-pin charging, built-in magnets for phone/EDC
attachment. ESP32-C3 based — which is why it can run community firmware.

## Why it matters
The X4 Pro ships with locked-down stock firmware; installing
[[Wiki/concepts/crosspoint-firmware\|crosspoint-firmware]] turns it into a fully hackable, wireless-capable
reading device. Units bought from xteink.com ship with unlocked USB flashing.
