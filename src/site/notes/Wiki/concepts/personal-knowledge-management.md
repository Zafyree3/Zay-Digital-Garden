# Personal Knowledge Management

**PKM is a system for capturing, connecting and re-using what you learn** — built on
the idea that insight lives in the **links between notes**, not in any single note.
A vault of well-connected notes lets you find things you'd forgotten you knew.

## The core moves
1. **Capture** — every idea, note or source gets written down somewhere, immediately
2. **Connect** — link each new note to what it relates to; the links are the value
3. **Re-use** — reviews (daily/weekly) surface old notes next to new ones, which is where cross-domain thinking happens
4. **Prune** — merge, rename and re-link as the structure becomes clear. Structure should *emerge*, not be designed upfront

## The vocabulary
- **Vault** — an Obsidian folder of plain Markdown files. Mine is a git repo so every change is versioned.
- **Second brain** — the popular framing: an external, searchable extension of memory.
- **Bi-directional linking** — every `link` is also a backlink, so a note knows what points at it.
- **Topic vs tag** — tags say what a note *is*; topics say what it's *about* → [[Topics/Organisation\|Organisation]]
- **Map of Content (MOC)** — a hub note that indexes a cluster and names the thread joining it

## How it works in *this* vault
- **Structure:** [[Structure\|Structure]] — the filing-cabinet metaphor
- **Conventions:** [[Topics/Organisation\|Organisation]] — tags, topics, the folder rules
- **The map:** [[Map of Content\|Map of Content]]
- **Two-link rule:** a keyword gets its own note only if it would be linked from 2+ places — otherwise it stays bold inside its parent note
- **Course notes:** `Study/<Course>/NN — Title.md`, with flashcards in the note itself
- **Published vs private:** a note only goes public if it says `dg-publish: true`; the public side is the [[Digital Garden/🏡 Digital Garden Home\|digital garden]]

## Why it's worth the upkeep
The vault isn't a filing system — it's a **thinking tool**. The value shows up when
two unrelated areas touch: first-aid ABC logic reappears in rescue drills; the
"verify by reversing" habit from calculus applies to a factorisation check. Those
connections only surface because the notes are linked.
